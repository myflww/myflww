## 正在做的项目

### Luma Companion

Luma 是围绕真实任务与角色陪伴组织的桌面软件项目。希望让 AI 工作台、桌宠和虚拟办公室在同一个桌面体验里协同工作。

- **任务与工作台**：围绕任务组织交互，连接 AI 执行能力与本机应用。
- **角色与场景**：桌宠、虚拟办公室与角色互动。
- **创作与扩展**：画布、剧场，以及配套官网与自托管服务模块。

项目持续开发中，各模块的实现与交付状态分别维护。核心源码目前在私有仓库保存，此主页用于公开介绍方向与进展。

## 项目使用的技术

| 范围 | 技术 |
| --- | --- |
| 桌面应用 | Electron · TypeScript |
| 界面与场景 | React · Pixi.js |
| 工程工具 | Vite · Vitest · Node.js |

## 关注的方向

AI 桌面应用、任务协作、角色陪伴，以及能在日常使用中持续打磨的软件体验。
