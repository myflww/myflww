## 项目

### Luma Companion

[![Luma Companion：工作、创作与角色陪伴](https://raw.githubusercontent.com/myflww/luma-companion-releases/main/assets/promo/hero-ensemble.png)](https://github.com/myflww/luma-companion-releases)

[项目介绍](https://github.com/myflww/luma-companion-releases) · [使用手册](https://github.com/myflww/luma-companion-releases/blob/main/docs/USER_GUIDE.zh-CN.md) · [获取版本](https://github.com/myflww/luma-companion-releases/blob/main/DOWNLOADS.md)

Luma 围绕真实任务与角色陪伴组织桌面体验，让 AI 工作台、桌宠和虚拟办公室相互衔接。

- **任务与工作台**：围绕任务组织交互，连接 AI 执行能力与本机应用。
- **角色与场景**：桌宠、虚拟办公室与角色互动。
- **创作与扩展**：画布、剧场，以及配套官网与自托管服务模块。

核心源码保存在私有仓库；公开项目页提供项目介绍、使用手册、许可说明和版本获取信息。
